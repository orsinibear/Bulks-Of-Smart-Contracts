================================================================================
ERC-20 Allowance Bypass Vulnerability - Proof of Concept Package
================================================================================

This package contains a complete, runnable Proof of Concept demonstrating the
ERC-20 allowance bypass vulnerability where spenders can force token owners
to pay extra fees beyond the approved allowance.

2. SUBMISSION.md

3. foundry.toml
   - Foundry configuration
   - Solidity compiler settings

   - Automated setup and execution script

   - Implements fee mechanism without proper allowance checks

7. test/AllowanceBypass.t.sol
   - Main PoC test: test_transferFrom_exceedsApprovedAllowance()
   - Demonstrates the vulnerability
   - Includes comparison test showing correct behavior

8. .gitignore
   - Git ignore patterns for Foundry projects

QUICK START
================================================================================

1. Install dependencies:
   forge install OpenZeppelin/openzeppelin-contracts --no-commit
   forge install foundry-rs/forge-std --no-commit

2. Run the PoC:
   ./run-poc.sh
   
   OR
   
   forge test --match-test test_transferFrom_exceedsApprovedAllowance -vvv

================================================================================
WHAT IT PROVES
================================================================================

The PoC demonstrates that:
- Alice approves 100 tokens to a spender
- Spender calls transferFrom(100)
- Alice loses MORE than 100 tokens (110 tokens: 100 + 10% fee)
- The balance decrease (110) exceeds the approved allowance (100)
- This violates ERC-20 standard expectations
